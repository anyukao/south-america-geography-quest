# Географический квест «История исследования Южной Америки»

Веб-приложение на Python + Flask для самостоятельного прохождения учениками интерактивного квеста.

## Возможности
- 5 станций: Колумб, Веспуччи, Кабрал, Гумбольдт, Дарвин.
- Итоговая викторина из 8 вопросов.
- Ученик сразу видит балл и разбор ответов.
- Результаты сохраняются в SQLite.
- Панель учителя с общей таблицей и выгрузкой CSV, которую можно открыть в Excel.

## Запуск на компьютере

1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Создайте виртуальное окружение и установите зависимости:

   Windows:
   ```bash
   py -m venv .venv
   .venv\\Scripts\\activate
   pip install -r requirements.txt
   ```

   macOS/Linux:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

4. Задайте пароль учителя (рекомендуется заменить пароль по умолчанию):

   Windows PowerShell:
   ```powershell
   $env:TEACHER_PASSWORD="ВашНадёжныйПароль"
   $env:SECRET_KEY="ДлиннаяСлучайнаяСтрока"
   ```

   macOS/Linux:
   ```bash
   export TEACHER_PASSWORD="ВашНадёжныйПароль"
   export SECRET_KEY="ДлиннаяСлучайнаяСтрока"
   ```

5. Запустите:
   ```bash
   python app.py
   ```
6. Откройте в браузере `http://127.0.0.1:5000`.

## Размещение на Render

1. Создайте аккаунт на GitHub и Render.
2. Загрузите содержимое этой папки в новый GitHub-репозиторий.
3. В Render выберите **New → Web Service** и подключите репозиторий.
4. Render обычно распознаёт `render.yaml`. Если настройки нужно ввести вручную:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app`
5. В Environment добавьте:
   - `SECRET_KEY` — длинное случайное значение;
   - `TEACHER_PASSWORD` — придуманный вами пароль.
6. Нажмите Deploy. После публикации Render покажет публичный адрес сайта.

## Важно о бесплатном размещении и сохранении результатов

Бесплатные веб-сервисы могут переводить приложение в режим сна. Кроме того, файловая система бесплатного веб-сервиса может быть временной: база SQLite в таком случае не гарантирует постоянного хранения результатов после перезапуска или повторного развёртывания.

Для реального урока, где важны результаты всех учеников, перед публикацией подключите постоянное хранилище или внешнюю PostgreSQL-базу данных. Не используйте сайт как единственное место хранения оценок без предварительной проверки. Для демонстрационного урока можно также заранее скачать CSV после прохождения теста.

## Адрес панели учителя
`/teacher/login`

Пароль задаётся переменной окружения `TEACHER_PASSWORD`. Не сообщайте ученикам пароль учителя.

## Конфиденциальность
Для прохождения теста запрашиваются только имя/фамилия (или выбранное вами обозначение ученика) и класс. Не просите вводить телефон, адрес, личную почту или другие лишние данные.
