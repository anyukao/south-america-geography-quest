# Исследование Южной Америки

Веб-приложение на Python и Flask для изучения истории исследования Южной Америки.

## Возможности
- Информационные станции о путешественниках и учёных.
- Биографическая информация и сведения об экспедициях.
- Навигация между станциями.
- Адаптивная страница для просмотра на компьютере и телефоне.

## Запуск локально

1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```bash
   python app.py
   ```

5. Откройте `http://127.0.0.1:5000`.

## Размещение на Render

- Build Command: `pip install -r requirements.txt`
- Start Command: `gunicorn app:app`

После отправки изменений в подключённую ветку GitHub Render сможет автоматически выполнить новый Deploy.
